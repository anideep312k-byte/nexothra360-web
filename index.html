Core Capabilities

Multi-Tenant Backend

SQLite + PostgreSQL with strict tenant isolation across all queries.

JWT + RBAC

11 SOC roles with 30+ fine-grained permissions, enforced at the API layer.

Durable Message Bus

DB-backed queue with DLQ, lease semantics, and backpressure handling.

Ingest Pipeline

Normalize → validate → enrich → dedup. Syslog TCP/UDP, file tail, HTTP ingest.

Detection Engine

Built-in Python rules + optional YAML loader with MITRE ATT&CK mapping.

Correlation

Entity-based incident grouping with bounded timeline and state machine.

UEBA

Online mean/variance baselines per entity and metric with anomaly scoring.

IOC Store

IPv4, domain, SHA256, URL tracking with tenant-scoped matching and expiry.

Risk Engine

Multi-factor scoring across severity, confidence, entity state, IOC, anomaly.

AI L1–L5

Rule-based + statistical pipeline with optional LLM provider integration.

SOAR

Propose / approve / execute / rollback actions with kill switch.

Hash-Chained Audit

Immutable SHA-256 chain with periodic anchors and verification API.
